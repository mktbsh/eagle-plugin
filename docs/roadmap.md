# Roadmap

The first public release established a reliable Vanilla TypeScript Window workflow. The next major work expands the same command surface to the remaining Eagle plugin forms.

## Current

- Typed manifest trust boundary.
- Window production build.
- Window development bridge and Eagle 4.0 HMR verification.
- Release preflight with mechanical errors, warnings, and manual checks.
- npm packages and Changesets release management.

## Planned

1. Template catalog and non-interactive project selection.
2. Background Service generation and end-to-end build.
3. Format Preview generation with Thumbnail and Viewer roles.
4. Inspector-only and combined format groups.
5. Four-topology consumer and Eagle acceptance matrix.

See the [framework specification](/specs/0001-eagle-plugin-framework) and [generator selection contract](/specs/0002-create-eagle-plugin-topology-selection) for the detailed boundaries.
